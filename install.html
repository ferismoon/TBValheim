Updating an existing installation

  1. Before updating, unequip the Atlantean Crown if you use it.

    Vikings Do Swim is being removed, including its diving feature and crown.

  2. Close Valheim and extract the client ZIP.

    In Steam, right-click Valheim → Manage → Browse local files. Keep a backup of any personal mod settings you want to restore.

  3. Copy the extracted contents beside valheim.exe.

    Merge folders and replace matching files. The supplied BepInEx folder belongs beside valheim.exe, not inside another BepInEx folder.

  4. Run Remove Old Mods.bat from that game folder.

    This moves the retired Need for Speed, Reely Good Rod, Vikings Do Swim and Comfy Auto Repair files into a backup folder under TBPack-Removed-Mods. Leave that backup outside BepInEx. Wait for the script to finish successfully before starting the game.

  5. Launch through Steam and join.

    Keep your pack aligned with the server. Check your personal shortcuts and door preferences after updating.

The cleanup list is carried forward in future packs, so players who skip an update can still remove older retired mods. Always run the script supplied with the latest full pack; copying new files alone does not remove old mods.

Installing for the first time

  1. Install Valheim through Steam and launch it once.

    Close it before installing the pack.

  2. Download and extract the full client ZIP announced in Discord.

    Use a clean game installation without unrelated mods.

  3. Open Steam → Valheim → Manage → Browse local files.

    Copy the extracted contents into this folder. BepInEx, winhttp.dll and doorstop_config.ini should sit beside valheim.exe.

  4. Launch through Steam.

    Let the mods finish loading, then use the server details in Discord.
