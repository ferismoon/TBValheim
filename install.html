Ready for the next voyage?

The pack download and server address are in our Valheim Discord channel. You must already have access to the True Bastards Discord to open the channel.

Already have pack 1.0?

Download TBValheim_Update_1.0_to_1.0.1.zip from the Valheim Discord channel. You do not need the full pack again.

  1. Close Valheim completely.
  2. Extract the update ZIP.
  3. Copy its BepInEx folder into the same game folder or Thunderstore profile where you installed 1.0. Merge folders and replace matching files when asked. Do not put it inside the existing BepInEx folder.
  4. Launch the game using your usual method and reconnect.

The update adds First Person and Auto Close Doors. If you tested an earlier door-mod build, replace it with the included version and remove any extra copy stored in another plugins folder.

New player? Use the full TBValheim_1.0.1.zip and follow the steps below. The update ZIP cannot install the pack on its own.

Windows / Steam · Pack 1.0.1

This guide is for the supplied TBValheim_1.0.1.zip. Use the whole pack so you get our settings and included compatibility patch.

Install the supplied ZIP

  1. Install and launch Valheim once.

    Close the game before adding the pack.

  2. Download the pack from Discord.

    Get the current ZIP from the Valheim channel and extract it somewhere easy to find.

  3. Open your Valheim game folder.

    In Steam, right-click Valheim → Manage → Browse local files. This is the folder containing valheim.exe.

  4. Copy the extracted contents into that folder.

    The BepInEx folder, winhttp.dll and doorstop_config.ini belong beside valheim.exe, not inside another pack folder. Merge folders and replace the pack’s matching files when asked.

  5. Launch Valheim through Steam.

    Let the first modded launch finish. Find the server address and joining details in Discord, then connect.

Already using mods?

Use a clean installation or a separate profile. Adding the pack over unrelated mods can leave extras behind.

If you use Thunderstore Mod Manager, create a dedicated Valheim profile, open its folder through Settings → Browse profile folder, copy the bundle contents there, and use Start modded.

This ZIP is a folder bundle, not a profile-code export. Don’t use “Import local mod” for it.

Updating the pack

For 1.0 → 1.0.1, use the smaller update ZIP linked in Discord. Both downloads contain the same new mods; choose the full ZIP only for a fresh installation.

Keep your version aligned with the server rather than updating individual mods separately.

Choose your door timer

Once connected, open F1 → TrueBastards Auto Close Doors → 2 - My doors. Select ServerDefault, CustomTimer or NeverClose. If you choose CustomTimer, also set Custom delay seconds.

Read the Auto Close Doors guide →

Try first person

Press F6 to switch between first and third person. The camera can temporarily return to third person during combat or manual zoom. Camera preferences are personal; you can keep using third person.

Something isn’t right?

Post in the Valheim channel with what happened, your pack version and any error message. If “The Gods Reject You” appears on an older character, mention which bosses you already defeated.
